# Отчет по выполнению задания №3
**Тема:** Использование структур для представления данных. Реализация модели КИС-2.

## 1. Overview (Обзор)
Данная программа предназначена для управления списком товаров (`TOVAR`). Она позволяет вводить данные о товарах, рассчитывать их среднюю стоимость, сортировать список по цене и фильтровать товары, поступившие на склад более 10 месяцев назад.

Программа реализована с разделением на:
- **Интерфейс (tovar.h):** Описание структур и прототипов.
- **Сервер (server.c):** Логика обработки данных.
- **Клиент (client.c):** Взаимодействие с пользователем.

## 3. Описание структур данных
В программе используются две связанные структуры:

1. **DATE:**
   - `int day, month, year` — дата поступления.
2. **TOVAR:**
   - `char name[50]` — название.
   - `int count` — количество.
   - `float price` — стоимость.
   - `DATE arrival_date` — дата (вложенная структура).
